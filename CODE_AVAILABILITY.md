# Code availability

The released scripts cover the data-generation path, boundary-enhanced ConvNeXt surrogate-training implementation, and finite-periodic Abaqus input-deck construction. They are included as an executable methodological record. The `README.md` commands run without a trained checkpoint and therefore validate interfaces and workflow only, not the manuscript's full-dataset performance claims.

The repository intentionally excludes trained weights, environment-specific paths, full active-learning run archives, and proprietary or bulky solver artefacts. The released source is not an open-source licence grant; use is limited by `LICENSE.md`.

Suggested manuscript wording after the repository URL is known:

> Analysis and demonstration code are available at [REPOSITORY_URL]. The released package contains the scripts required to reproduce the workflow on the accompanying minimal demonstration data; trained checkpoints and full run archives are available for editorial or non-commercial validation upon reasonable request.
