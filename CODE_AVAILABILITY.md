# Code availability

The released scripts cover the data-generation path, boundary-enhanced ConvNeXt surrogate-training implementation, and finite-periodic Abaqus input-deck construction. They are included as an executable methodological record. The `README.md` commands run without a trained checkpoint and therefore validate interfaces and workflow only, not the manuscript's full-dataset performance claims.

Trained weights, environment-specific paths, full active-learning run archives, and large solver artefacts are not included in this demonstration repository. Further technical information can be requested from the corresponding author.

Suggested manuscript wording after the repository URL is known:

> Analysis and demonstration code are available at https://github.com/eeee-AI/phononic-crystal-bandgap-inverse-design. The released package contains the scripts required to reproduce the workflow on the accompanying minimal demonstration data; trained checkpoints and full run archives are available from the corresponding author upon reasonable request.
