# Data availability

The repository provides rendered unit-cell images, centre-frequency labels, inter-bandgap records, a representative Abaqus unit-cell mesh, and band-structure output files. The data files are located in `data/`, `abaqus/unit_cell/`, and `results/`.

Suggested manuscript wording:

> Code and data supporting this study are available at https://github.com/eeee-AI/phononic-crystal-bandgap-inverse-design.
